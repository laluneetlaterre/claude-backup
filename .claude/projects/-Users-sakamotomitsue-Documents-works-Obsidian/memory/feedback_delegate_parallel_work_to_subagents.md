並行作業をさせたいとき、別タブで2人目の司令塔を開くと、2つのタブは**対等で互いに見えず話せない** → Miey が御用聞き（伝書鳩）をやる羽目になる。代わりにメインタブの司令塔に Agent ツールでエージェントを生ませれば、エージェントは司令塔の**部下**として動き、司令塔が割り振り・進捗管理する → Miey は中継不要。

**Why:** 2026-06-16、別タブで別冊HTML化を進めた際、2タブ間を Miey が手動中継するハメになった。司令塔配下のエージェントなら一元管理で中継が消える。Miey 自身が「別タブを開く代わりに『司令塔、○○はエージェントに振って』と言えばよかった」と気づいた。

**How to apply:**
- Miey が「手放しでいい並行作業（例：別冊HTML変換・画像埋め込み）」をさせたいときは「**司令塔、○○はエージェントに振って**」の一言。司令塔がエージェントを起動・統括する（司令塔は勝手にエージェントを起動しない＝Mieyの明示依頼が起点）。
- **使い分け**：協業・文脈が重い・Miey の反応を見ながら直す作業（例：拡張編の実機テスト＆推敲）は、エージェントでなく**メインタブで司令塔と一緒に**。エージェントは記憶ゼロで始まり、Miey の目の前で動かないため、生の詰まり（実機バグ）を拾えない。
- エージェントの進捗は**メインタブの中**で見える（独立した別タブとしては開けない）。バックグラウンド実行なら完了時に通知が来る。
