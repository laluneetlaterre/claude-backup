ユーザー（Miey）が入力した内容を、AI側の判断で勝手に削除・除外・縮約しない。たとえ「絞り込みすぎると結果が0件になる」「クエリが長すぎて検索精度が落ちる」といった技術的に妥当な理由があったとしても、それを判断するのはユーザー本人。

**Why:**
不動産物件ランチャー実装中（2026-05-28）、ユーザーが入力した「専有面積200㎡以上」「賃料80万円以下」等の条件を、私が「Google 検索で絞り込みすぎると0件になる」と判断して勝手に Google クエリから除外した。Miey から「私が入力した200㎡が検索窓に出てこない」と指摘され、判断ミスが発覚。Miey は「自分の入力がそのまま反映されること」を期待しており、AIが「親切心」で削減することは「裏切られた」感覚につながる（Miey の HSP 傾向とも関連）。

Rule 2「外科的編集の鉄則」の精神：指定された範囲を勝手に変えない。これは入力データの扱いにも適用される。

**How to apply:**
- フォーム入力、検索条件、データのフィルタリング、エクスポート対象の選択 — どんな文脈でも、ユーザーが指定した内容は「すべてそのまま使う」が初期値
- 「絞り込みすぎ」「冗長」「効率悪い」等の懸念がある場合は、勝手に削るのではなく、UIで明示（警告表示、結果が少なすぎたら絞り込みを緩める提案など）し、最終判断をユーザーに委ねる
- 例外：明らかに技術的に不正な入力（不正な型、文字数オーバー等）の場合のみ、システム側でハンドリングしてユーザーに通知
