**「AI記憶の書斎」の主ターゲット＝副業をやっている人**（2026-07-26 Miey決定）。

## 設計の核：diary継続を前提にしない

**diary は「書け書け」と勧めるものではない。「書けばあとで参考になる」程度に置く。** diary が続く人は稀。続かないと価値が出ない設計は、その時点で欠陥。

副業層をターゲットにすると、これが解決する。副業をやっている人は**最初から管理するものを持っている**（在庫・売上・経費・発送・顧客）。空の Vault を前に「何を書けばいいの？」にならず、実務で毎日開くので、**diary が続かなくても Vault は死なない**。

## 想定する使われ方（＝Miey 自身の使い方そのもの）

日々ヤフオク・メルカリ等の副業に役立てながら、`思考_自己分析` フォルダに四柱推命等の鑑定書を置いておき、**自分を静かに振り返る瞬間を楽しむ**。実務が主、自己理解は義務ではなく楽しみとして上乗せ。

- **入口** ＝ 副業効率化（オークション・事務）
- **部屋** ＝ AI記憶の書斎
- **静かな楽しみ** ＝ 自己理解（四柱推命・数秘術という表現形式）

→ [[project_positioning_many_doors_one_room]] の「入口は複数・部屋はひとつ」の具体的な実装。2026-07-26 に YouTube の最初の看板を**オークション編**に決めたのも同じ線。

## お金まわりは「会計」と呼ばない（2026-07-27 Miey決定）

**「会計」ではなく「お小遣い帳・家計簿」として出す。** これで2つ解決する。
- **責任が消える**：会計だと確定申告の正しさに責任が発生する。お小遣い帳なら「記録を助けるツール」で済み、税務の線引きを気にせず出せる（それでも「税務相談ではない」の但し書きは入れる）
- **対象が広がる**：「会計」に反応するのは既に事業をやっている人だけ。お小遣い帳・家計簿なら**これから副業を始める人**にも届く。溜まれば結果的に確定申告の材料になる＝軽い入口で入って重い用途に育つ

実装も凝らない。**月1ファイルにMarkdown表**（日付・内容・金額・区分）から始め、集計は Claude Code に頼む。`.base` もスクリプトも、足りなくなってから足す。

## 商品の出し方：LPは複数・着地は1つ

入口ごとに LP／広告を作り分け、**着地する商品は同じ1つに集約する**（2026-07-27 Miey）。見出しと冒頭3行だけ差し替え、中身は共通。
例：「メルカリ・ヤフオクの記録が面倒な人」向け／「副業のお金の出入りが分からない人」向け／「AIに毎回同じ説明をしている人」向け。

出す順番：**第1弾＝メルカリ・ヤフオク編**（台帳・スキル5本が完成済みで今すぐ出せる。YouTube 1本目のオークション編がそのまま導線）→ **第2弾＝お小遣い帳・家計簿**（検証相手は要再選定。下記参照）。四柱推命は売り文句の主役にせず「中に自己分析の部屋があって鑑定書を置ける」と説明するだけ。

## Ben をパイロット顧客にする案は没（2026-07-31）

Ben に会計まわりを実験台として頼む案は**没**。Ben 本人が「会計にAIは要らない、手動のほうが早い」と回答。弥生との突き合わせ検証ルートも消滅。

**この否定が意味すること：** Ben は**すでに自分のやり方が完成していて、量も安定している実務者**。この層には導入コストが利益を上回るので、そもそも売れない。つまり顧客は「副業をやっている人」全般ではなく、**副業をやっていて、記録が散らかる・忘れる・複数案件が並走している人**（＝Miey 型。[[user_adhd_multitool_affinity]]・[[user_neuro_profile]]）。商品の否定ではなく、**検証相手を間違えていた**という情報として扱う。

次の検証相手は身内から探さず、YouTube で人が来てから自然に集まる層で取る。身内に頼む案が再浮上したら、まず「その人はもう回っているか？」を確認する。

## 打ち出し方の注意

**「副業で稼ぐ方法」ではなく「副業の面倒を仕組みにする方法」**として立てる。副業系の発信は飽和しているが、「Obsidian × Claude Code で副業の事務を仕組み化する」まで踏み込んでいる人はほぼいない。稼ぎ方の話にすると既存の副業インフルエンサーと正面衝突するので、そこへ寄せない。

**Why:** 従来の商品設計は「diary を書き続けること」に価値の証明責任を置いていた。2026-07-26 の市場分析で司令塔がこれを最大の構造リスクとして指摘し、Miey が「そもそも diary を強制しない／副業層をターゲットにする」という形で解答を出した。

**How to apply:** 教材・LP・YouTube・レッスンの導入で「毎日書いてください」を要求しない。実務（副業の事務）で毎日開く動線を先に作り、自己理解フォルダは「置いてあるだけ・たまに覗く」位置づけで紹介する。関連：[[project_brand_ai_kioku_no_shosai]]、[[project_harm_five_pillars]]（Money/Ambition◎）、[[feedback_obsidian_construction_sales_copy]]
