Miey が Obsidian から外部（Cafetalk・ヤフオク・note 等）へ貼るものは、**全文をひとつのコードブロックに入れ、言語タグなしの ``` フェンス**で囲む（2026-08-07 Miey指示「これからobsidianのコードブロックは、今のように一発コピーできるようにしてね」。この日 Miey 自身が ```html → ``` に直した形が「今のように」の実体）。

**Why:** コピーボタン1回で全文が取れないと、手で範囲選択することになり、貼り漏れ・末尾欠け・崩れの事故が起きる。Cafetalk のレッスンページは HTML 全文を貼り直す運用なので特に効く。[[reference_cafetalk_html_constraints]]

**How to apply:** 説明・注意書きはフェンスの外に出し、フェンス内は「貼るものだけ」。長くても分割しない（分割＝コピー回数が増える）。言語タグ（```html 等）は付けない。既存ファイルには ```html 形式が34件残っている（products・03_stock/auction 出品メモ等）＝一括変換は Rule 3 で要 Miey GO。関連 [[feedback_full_filenames_no_abbreviation]]
