X 投稿の第1ツイート（フック）訴求軸は、**個人ストーリー / Miey らしさ反転型ではなく、事業継続・構造論・unfair advantage 軸で組む**。

**Why（理由）**：Miey は X 上で熱量高いファン基盤がまだ確立されていない（Miey 自認 2026-06-03）。個人語りは「で、誰？」となって流される。司令塔が今回「ADHD 反転型を第1ツイートに推す」と提案した際、Miey から「私のファンには効くだろうけど、ファンはいない」「案A 直接対比は嫌味に聞こえる」と訂正を受けた。誰でも納得できる構造論（1社依存の弱点・事業継続・冗長性・unfair advantage）を起点にすると、ファン基盤の有無に関係なく刺さる。

**How to apply**：
- 司令塔が「Miey 文体・固有性軸」を推したくなる場面で、まず「ファン基盤」状況を踏まえる。ファンがいる前提のキャラ投稿は効かない。
- 第1ツイートは構造論軸（誰でも納得できる事業継続・冗長性論）で立ち上げる。
- Miey 個人性（ADHD 親和性・体験談）は本文中段以降に降ろし、「合う人・合わない人」枠で自然に出す程度に。
- 結びは unfair advantage 直球（[[feedback_obsidian_construction_sales_copy]]）で締める。
- ターゲット競合（30人 AI 社員モデル等）への直接言及は避け、概念中心化（「Claude Code 内組織化」「AI 内に役割を増やす運用」等）でリフレーミング。数字や固有名詞（ポケモン名等）は特定リスクを生むので削除。

**反対側の例外**：将来的に Miey の X ファン基盤が確立されたら、個人ストーリー軸も解禁できる。本ルールは「現時点（2026-06）の判断軸」として運用。
