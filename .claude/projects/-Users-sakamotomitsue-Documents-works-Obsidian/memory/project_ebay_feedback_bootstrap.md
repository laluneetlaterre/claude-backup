Miey の eBay 口座は評価がほぼゼロ。**高額・無傷の定番品（アルマ、ペガス等）は「買い手に拒否されている」のではなく「検索結果に表示されていない」。** Top Rated・米国内・返品可・数千評価のセラーが並ぶ混雑プールでは、新規口座は最下部に沈む。

2026-08-15 時点の実データ（30日 views / watchers）がこれを裏づけた：Speedy 30 `Damaged Repair AS-IS` $169 = **44 / 5**、Mini Lin `Damaged AS-IS` $245 = **34 / 3** に対し、Pégase 55 $860 = 10 / 0、アルマ PM $299 = 3 / 0、財布 $99.99 = 1 / 0。

**効いている要因は価格の安さではなく、競合の薄いロングテール語。** `damaged` `AS-IS` `for repair` `junk` は、修理屋・転売屋・アップサイクル層が自分から打つ語で、供給が薄いため**ランキング権限ゼロでも1ページ目に出る**。また「価格の安い順」ソートは Best Match を迂回する唯一の導線。

**How to apply:** 破損が実在する品はタイトルに `AS-IS` / `Damaged` / `For Repair` を入れて勝てるプールへ移す（集客と、not-as-described への防御を兼ねる）。**安い品を早く売って評価を作ることを、高額品を売るための投資として扱う**——$149 のバッグを $129 で手放すのは $20 の損ではない。ただし「安い破損品が本業」と読み替えないこと。順位が取れる場所であって需要が大きい場所ではない。関連： [[feedback_price_from_sold_not_asking]]、[[project_auction_sales_ledger]]。
