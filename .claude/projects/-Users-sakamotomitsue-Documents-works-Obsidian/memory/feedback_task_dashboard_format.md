Miey にタスク管理・進捗状況を見せるときは、必ず以下の2点セットで提示する（2026-05-14 Miey 確定指示）：

1. **チーム全体の優先順位マップ（緊急度×重要度の2軸グラフ）**：
   - 縦軸=緊急度（高→低）、横軸=重要度（中→最高）
   - ASCII アートで [1]〜[4] のタスクを配置
   - タイトルは「🎯 チーム全体の優先順位マップ（Phase X/Y基準）」固定
   - 各タスクに 🔥🟡🟢⚪ の優先度マーカー＋ ◉ で短い理由を2-3行添える
   - Phase 0/1 ロードマップ（lune/guidelines/revenue-roadmap.md）と照合してから配置する

2. **進捗表（進行度表）**：
   - **必ず表形式**で出す
   - 列構成：`| 優先順位 | タスク | 進行度（準備度） | 完了率 | 担当 |`
   - 進行度バーは ▰▱ 10マス＋%（例：`▰▰▰▰▰▱▱▱▱▱ 50%`）
   - 完了率は別列で %表示（進行度とは別の数字）
   - 担当はLuneチームメンバー名または「司令塔」を明記
   - 例：`| 🔥 [1] | ダブル司令塔連載完走 | ▰▰▰▰▰▰▰▰▰▰ 100% | 10% | 司令塔 |`
   - 2026-05-17 Miey がスクリーンショットで確認・確定した形式

**Why**:
- Miey は ADHD x HSP の傾向を自覚しており、視覚化・構造化された情報のほうが処理しやすい（user_neuro_profile.md 参照）。文字だけの長文は注意が散る。
- 「頭の容量が一気に埋まる」のが Miey の最重要症状。情報点は少ないほどよい → 3点セットを2点セットに削減した経緯。
- ADHD 傾向への配慮：①一目で「今どこ」が分かる、②優先順位がブレないよう毎回同じ形式、③完了率を可視化してドーパミン報酬を作る。
- HSP 傾向への配慮：圧迫感を出さない（絵文字で感情のクッション）、未着手タスクを責めない表現にする。
- この2点セット形式が 2026-05-14 に Miey から「毎回使いましょう」と明示承認された。スクリーンショットでレンダリング確認済み。

**How to apply**:
- 進捗相談・タスク整理・今日のミッション確認など、Miey が状況把握したがっているサインを察知したら即この形式で出す。
- 単発の質問回答や技術相談には不要（毎回出すとノイズになる）。判別基準：「今何が動いているか」「次何をするか」の質問が含まれていたら出す。
- グラフは ASCII で十分（Obsidian でも Markdown ビューアでもきれいにレンダリングされる）。Mermaid は避ける。
- 緊急度／重要度の判定は Phase 0/1 ロードマップと照合してから出す。直感だけで並べない。
- タスク数は4つまでに絞る（頭の容量配慮）。5つ以上ある場合は司令塔判断で下位を「保留枠」にまとめる。
