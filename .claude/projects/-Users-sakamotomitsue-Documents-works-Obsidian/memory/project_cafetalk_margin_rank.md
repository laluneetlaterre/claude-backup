Cafetalk のマージンレートは毎月1日に洗い替えられ、①保証レート（累計売上）②変動レート（直前2ヶ月の良い方の月商）③信頼性ボーナス（2ヶ月連続で有料1件以上＋no-show無し）の**いちばん良い条件**が適用される。Miey の現在値は **65%**（2026-08時点・累計286,550pt）。**70%保証は累計500,000pt から**（あと約21万pt）。

**Why:** 2026-04〜06 の3ヶ月連続ゼロで 70%→65% に落ちた（2025-08 も 2025-06 のゼロが原因）。1本 10,000pt のレッスンで **¥500/本** の差になる。「Cafetalk は重要視しない」方針（[[project-cafetalk-reuse-policy]]）でも、完全に止めると手数料で取られる。

**How to apply:** Cafetalk の単価・手取りを計算するときは **65%**（過去平均69%を使わない）。70%に戻す最短は「月商20,000pt＝1万ptレッスン2本」か「月1本でいいので有料を切らさない」。休止提案が出たら、この5%のコストを必ず添える。規則の検証と全期間データの正本は `03_stock/cafetalk/レッスン履歴/レッスン履歴メモ.md` §1（[[project-cafetalk-high-price-only]] も参照）。
