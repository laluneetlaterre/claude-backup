**方針（2026-05-16 改訂・v0.9）**：仮想経営チームのツール構成と役割。

| 役割 | AI | 用途 |
|---|---|---|
| 司令塔・実行 | Claude Code（Opus） | 全 AI の方針整理・優先順位・統合判断・実行・エージェント運用 |
| 参謀・壁打ち・長文思考 | Codex（GPT-5.5 Medium / High） | 普段の頭脳は Medium、難題は High。設計レビュー、異論・改善案、リスク指摘 |
| 軽作業・検索・補助 | Gemini Code Assist | Google 系連携、軽い調査・補助、気軽な使い回し |
| 大量読み込み・要約 | Gemini CLI | 大量ソースの Ingest・要約・分類タグ付け（並行運用） |
| 局所補完 | Copilot | コード補完・定型処理補助 |
| 非常時バックアップ | Cursor | 保険。2026-06-11 廃止予定 |

**Why**：Miey の弱点（マーケ・商品開発）に対しては、ツール統合の精巧さより「1ツールで稼いだ実体験」のほうが教材として再現性がある。だが参謀（Codex）を加えることで、司令塔（Claude Code）の盲点・矛盾・改善余地を能動的に出す体制を作る。Codex は盲従ではなく異論を出す立場。

**How to apply**：
- Miey からの新ツール導入・運用変更の報告は §4.1「チャレンジ報告応答プロトコル」の5項目で機械的にチェック（指揮系統の空白／編集権限階層／大規模操作該当／経済的圧力／撤退条件）。
- 司令塔（Claude Code）は各 AI に直接命令できない。Miey が各 AI に指示を投入する。司令塔の役割は方針整理・優先順位・統合判断・指示文設計。
- 参謀（Codex）は司令塔の方針に異論を出してよいが、Miey の最終承認権限を越権しない。
- 外部影響のある操作（ファイル編集・コマンド実行・Git・送信・公開・削除・課金）は Miey 確認が必要。

**禁則**：クレジット切れ期間を別ツールで埋める運用は採用しない（司令塔不在の空白を生み、ルール解釈・横断判断ができる主体がいない状態で副官が独自判断するリスクが高いため）。Cursor pro は 2026-06-12 にクレジットがリセット（30日間）。**クレジットを使い切り次第解約**（pro 契約は継続しない）。クレジット切れ期間は AI 作業を止めるか Miey 自身が手動で進める。

**Gemini CLI と Gemini Code Assist は別物・並行運用**：
- Gemini CLI = ターミナル CLI。`~/.gemini/GEMINI.md` を起動時に自動読み込み（master ポインタ）。大量読み込み・要約担当。
- Gemini Code Assist = VSCode 拡張。軽作業・Google 系連携。
- どちらも残す。Cursor が 2026-06-11 で廃止予定なのとは別の扱い。

**Cursor の使い道**：Cursor マニュアル教材作成も兼ねて、タブ並行・インライン編集系の作業を寄せる。master ルールや handoff の運用方針更新には触らせず、自分の作業報告だけを handoff に書く。

**Codex の参謀化（2026-05-16 設置）**：プロジェクト直下に `AGENTS.md` を新設し、Codex CLI が自動読み込み。master の同期コピー（ポインタ方式）。Codex は handoff にも自動読み込みで参加可能。

**3ツール統合運用**：売り物にしない。記事ネタとして低優先で温存。

- 2026-05-16：Codex を参謀として正式組み入れ。「交換日記」→「handoff」へ呼称変更。Gemini CLI と Gemini Code Assist を並行運用で確定。
