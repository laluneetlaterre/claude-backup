**方針**：VSCode Claude Code を司令塔（メイン）、Gemini CLI と Cursor を特化ワーカー（サブ）として分業。Cursor pro は 2026-06-12 にクレジットがリセット（30日間）。5/13 現在 20% 消費。**クレジットを使い切り次第解約**（pro 契約は継続しない）。

**禁則**：クレジット切れ期間を別ツールで埋める運用は採用しない（司令塔不在の空白を生み、ルール解釈・横断判断ができる主体がいない状態で副官が独自判断するリスクが高いため）。クレジット切れの2日間は AI 作業を止めるか Miey 自身が手動で進める。

**Cursor の使い道**：Cursor マニュアル教材作成も兼ねて、タブ並行・インライン編集系の作業を寄せる。master ルールや交換日記の運用方針更新には触らせず、自分の作業報告だけを ai-handoff に書く。

**3ツール統合運用**：売り物にしない。記事ネタとして低優先で温存。

**Why**：Miey の弱点（マーケ・商品開発）に対しては、ツール統合の精巧さより「1ツールで稼いだ実体験」のほうが教材として再現性がある。VSCode 派・Cursor 派双方に対応するなら、月替わり集中運用で別々のマニュアルを作るほうが質が高い。

**How to apply**：新ツール導入・運用変更の報告を受けたら、司令塔は「指揮系統に空白が生まれないか／編集権限階層が守られるか／大規模操作に該当するか／経済的圧力でルールを曲げていないか／撤退条件が決まっているか」を確認し、引っかかれば沈黙せず指摘する。

**学習日**：2026-05-13（Cursor で VSCode のクレジット切れを埋める案を司令塔が即時に止めなかった反省から）。
