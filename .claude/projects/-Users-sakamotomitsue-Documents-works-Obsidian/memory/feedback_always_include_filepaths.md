Mieyからの2026-05-24指示：「TIPS統合 取り込みマップのファイルのところに、そのファイルのパスも書いてくれない？ 司令塔の会話でも、パスがないとわからない、検索しないとどれかわからないものも多くて、読み取りが大変」

**Why**:
- Vault内のファイル名は重複や類似が多く、ファイル名だけだと「どれの話？」と検索が必要になる
- Mieyは ADHD x HSP 傾向（[[user_neuro_profile]]）で、画面上の判断疲労を避ける必要がある
- 検索の手間 = 判断疲労の蓄積 = フォーカス喪失（[[feedback_phase_progression_lead]] と整合）
- Markdownリンク形式なら：① Obsidian/VS Code で**クリック1発で開ける**、② リンクのhref部分にパスが入っているのでホバーで確認できる、③ 表示文字列はファイル名で読みやすい
- Mieyの所感：「Claude codeを使っている他の皆さんは理解できるのかな？タイトル名で検索しているってこと？」→ つまり、これは Miey 固有の困りごとではなく、Claude Code を普通に使う人みんなが遭遇する問題。司令塔側でカバーすべき

**How to apply**:

1. **diary・MEMORY.md・チャット出力すべて**：ファイルに言及するときは必ず `[表示ラベル](相対パス/ファイル名.md)` 形式
2. **表示ラベルにフルファイル名を書かない**（2026-05-24 追加）：表示ラベルと href 末尾のファイル名が同一だと **視覚的に冗長**。表示ラベルは **内容を表す短いラベル**（`.md` 拡張子なし、アンダースコアは適度に外す）にする。
   - ❌ 悪い例：`[ターミナル基本コマンド完全リファレンス.md](path/.../ターミナル基本コマンド完全リファレンス.md)` ← ファイル名が2回出てくる
   - ✅ 良い例：`[ターミナル基本コマンド完全リファレンス](path/.../ターミナル基本コマンド完全リファレンス.md)` ← .md 削る／別キーワードに置換
   - ✅ もっと良い例：`[ターミナル基本コマンド](path/.../ターミナル基本コマンド完全リファレンス.md)` ← さらに短く
3. **ベースパスは省略しない**：絶対パスではなく、Obsidian Vault ルート（または lune ルート）からの相対パスを使う。例：`products/Claude Code + .../10_/04_商品関連ツール解説/obsidian-skills_導入と使い方.md`
4. **表示文字列はファイル名のみ**：パスを表示文字列に入れると表が崩れる。href部分にパスを入れて、表示は短く
4. **削除済みファイルは取り消し線**：`~~ファイル名~~`（リンクにしない、もう存在しないので）
5. **大量のファイルを表で並べるとき**：列に「ファイル」「パス」を分けるより、ファイル名をMarkdownリンクにする方が読みやすい
6. **VS Code/Obsidian 環境**：Markdownリンクのパスは相対パスで OK。両方クリック対応

**例（良い）**：
```
| [obsidian-skills 導入と使い方.md](products/.../obsidian-skills_導入と使い方.md) |
```

**例（悪い）**：
```
| obsidian-skills 導入と使い方 |  ← ファイル名だけ、検索が必要
```

**判別基準**：チャットや diary で「○○というファイル」と書いたら、自動でリンク化されているか確認する。されていなければ即修正。
