Miey が自分の事業の **ベンチマーク（抜きたい相手）** として明示したのが「農家の嫁かすみ」。clippings に教材あり（Brain「【300部突破】AIに渡すだけ！Obsidianで作る自分専用ナレッジスタータキット」）。

**かすみのモデル（型が完成）：** 無料（メルマガ→Obsidianスターターキット「1st-farm」＋解説動画＋Udemy割引クーポン）→ Brain 500円から段階値上げ(現2,980)・アフィリ50%で拡散 → Udemy 27,800円(Obsidian基礎) → Kindle複数冊(1位7冠・権威付け) → コンサル(月10〜40万の生徒)。実績＝ブログ147万/YT累計1.5億/Udemy1500人。武器＝「農家の嫁・非エンジニア・アラフィフ」キャラ＋徹底的にやさしい間口。コンセプト＝「AIに振り回されない自分専用ナレッジ畑／AI＝優秀な新人ちゃん／複利で育つ」。

**Miey の差別化（同じ土俵で正面勝負しない）：** ①Claude Code×VS Code で AI がファイルを直接読み書きする"一段深い第二の脳"（かすみの「AIに読ませる」の一歩先）②四柱推命×AI×数秘術＝かすみに無い独自領域（Spiritual の柱）③構造の本格性（LLM Wiki / Ingest・Query・Lint / 3層）。→ **型（やさしさ・無料キット・ラダー・段階値上げ・アフィリ）は王道なので真似る。中身で独自を出す。**

**Kindle 出版志向：** Miey は Amazon 本も出したい。KDP は無料で誰でも出版可。本編「AI第二の脳システム」がマスター素材→Kindle化はその派生。役割＝著者の権威付け＋安い入口＋Amazon検索流入 → note・Cafetalk 高単価へ流す導線。

**リサーチで判明した数字（2026-06-16）：** Kindle「はじめてのObsidianのノート術〜AI時代を生き抜く第二の脳〜」(共著:凪沢勇志)＝初月705冊・初月印税22万円・総合24位・7冠・980円。Brain スタータキット＝400部突破(公開2週弱)。YouTube累計1〜1.5億・銀の盾(10万登録)。Udemy 1000〜1500名。ブログ最高月147万(過去ピーク)。現在の月収は非公開だが複数チャネル合算で月数十万〜100万超と推測（数字はマーケ盛りに注意。ブログ147万/YT1.5億は累計・ピークで現月収ではない）。

**重要な発見：** ①Mieyの貼ったnote(nagi001)は本人でなく**出版代行プロデューサー「凪沢勇志(なぎ)」**。かすみのKindleはこの人がプロデュースしたクライアント実績。→ MieyのKindleも自力KDP/出版代行の2択。②**「AI第二の脳」は既に激戦ワード**：かすみのKindleタイトルがコンセプト酷似、さらに競合本「Obsidian×AI自動化の教科書 Cursor/Claude Codeで」(くにふさりく)等が複数。Claude Code×Obsidian本はレッド化しつつある。→ 市場が実在する証明でもあるが、Mieyは商品名/Kindleタイトルで激戦ワードを避け、占い×AI(無競合)・Claude Code本格連携・構造の深さで差別化必須。
