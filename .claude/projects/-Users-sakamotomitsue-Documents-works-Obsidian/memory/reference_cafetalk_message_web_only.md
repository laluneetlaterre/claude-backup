Cafetalk のお客様（生徒）への連絡は **Gmail からメール送信できない**。Cafetalk の **Web 画面のメッセージ機能から送るしかない**。

**How to apply:** akiko さん等 Cafetalk 経由のお客様に連絡する依頼が来たら、Gmail の下書きを作らない。代わりに、Web 画面のメッセージ欄にそのまま貼れる **プレーンテキスト（コピペ用）** を用意して Miey に渡す。リンク（Notion 等）は URL をそのまま本文に入れれば Cafetalk 画面上でも機能する。

Cafetalk の連絡先メール（no-reply@cafetalk.com 経由の通知）に返信しても届かない点にも注意。HTML で渡す場合の Cafetalk 側の表示制約は [[reference_cafetalk_html_constraints]] を参照。
