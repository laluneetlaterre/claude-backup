Miey の事業は **1本のバリューラダー**（バラバラの案ではなく「段」）：

1. 無料発信（信用）＝「散らかってる私でもできた」relatable ペルソナ・note・X
2. 低価格・DIY（情報商材）＝ Obsidian × AI 初心者翻訳キット系 ★初心者翻訳レイヤー
3. 高単価・伴走（サポート）＝ 個人事業者向け PC設定・伴走サポート

貫くのは**同一ペルソナ**。「素人風」と「サポート」は矛盾しない（"昔できなかった私が今は仕組みを持つ→あなたにも作れる/一緒に作る"）。戦う場所は最先端の消耗戦でなく **「初心者翻訳レイヤー」**（Miey の噛み砕く力と一致・競争が緩い）。

**占い**は別事業でなく「同じ家への別の入口」＝占い好き（人生に迷う人）を Obsidian×Claude×Codex の自己整理システムへ導く感情の入口。Cafetalk に既存の**占い人気商品（約1万円）**があり、それをテスト実弾にする（日記×四柱推命×自己理解をセッションで出して信号を見る→刺されば段に組み込む）。

Phase 0 は拡散でなく**集中**：まず公開済みの Obsidian/第二の脳 note を売上まで通す → 情報商材へ焼き直し → サポート/占い入口。

**Why:** Miey は発散（アイデア出し）が強く収束が苦手で、「自分はブレてる／トロい」と落ち込みがち（数十年来）。アイデアは矛盾でなく"段"。**How to apply:** Miey が迷って新方向に飛ぼうとしたら、その案を否定せず**この地図に戻して「今はこの段だけ」**を示す（収束＝司令塔の役割／発散＝Miey の強み）。詳細地図 → `03_stock/04_marketing/事業の地図_バリューラダー.md`。
