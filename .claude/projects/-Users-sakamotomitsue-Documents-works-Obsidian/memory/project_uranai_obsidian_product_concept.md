四柱推命系商品の核は **Obsidian × Claude Code × 四柱推命 × 数秘術**。鑑定書を Vault に置き、日々の diary（行動・感情）を積み上げ、Claude Code が両方を読んで対話 → 出力を自己分析フォルダに蓄積 → 深掘りが一生続く「育つ自己理解システム」を売る。Miey 自身が現在実践中（diary/ ＋ 03_stock/05_思考_自己分析/ の構成）。

**Why:** 旧 Cafetalk 講座（NotebookLM 型）は Miey の中で「古い情報」であり継承しない（2026-06-12 明言）。鑑定書＝静的な設計図（仮説）、diary＝生きた検証データ、AI＝突き合わせて伴走する分析者。占いを「点」から「蓄積する螺旋」に変えるのが本質で、Obsidian 構築商品の「unfair advantage／蓄積した知性」フレーム（[[feedback_obsidian_construction_sales_copy]]）と完全に一致。占い＝同じ自己整理システムへの別入口（[[project_business_value_ladder]]）がこの商品で実体化する。

**How to apply:** 四柱推命関連の商品設計・レッスンページ・LP では NotebookLM ベースの構成を提案しない。常に「鑑定書を種に、diary を積み、AIと対話して深掘りし続ける環境を作る」構成で組む。Cafetalk 復活ページ（2026-06-12 草案）はこのコンセプトで要再設計（[[project_cafetalk_high_price_only]]）。
