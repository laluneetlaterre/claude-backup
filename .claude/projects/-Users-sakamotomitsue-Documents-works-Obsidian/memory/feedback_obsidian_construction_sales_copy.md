**ルール**：Miey の Obsidian 構築商品（[[products/Claude Code + Obsidianを組み合わせた「AI第二の脳」のシステム/10_第二の脳セットアップ_Obsidian構築]]）の **販売訴求文章**（LP・X 投稿・note・メルマガ・セールスレター・営業トーク）には、必ず「**unfair advantage / ズルいくらいの優位性 / 他人が持っていない武器 / 蓄積した知性そのもの / 圧倒的に勝つ**」のいずれかのニュアンスを最低 1 回は入れる。

**Why**：hooeem（@hooeem、商品の原典著者）が X 投稿（2026-04-07）で打ち出した核フレーミング："you're not selling software. you're selling **an unfair advantage** in their specific field."。購入者が買っているのは「ソフトの便利さ」ではなく「自分の専門分野での不公平なほどの優位性」。Miey が 2026-05-28 に「素晴らしいコピー案、絶対残して販売訴求文章には必ず入れて」と明示承認したフレーム。安く見られないための価格防御線でもある。

**How to apply**：
- 販売訴求文章を書く／レビューするタイミングで、本ルールが発動する
- メインコピー or サブヘッドに上記ニュアンスを最低 1 回入れる
- 「便利」「効率化」「時短」だけの訴求は **NG**（hooeem フレームから外れる）
- **コピーバンクの一次参照先**：`products/Claude Code + Obsidianを組み合わせた「AI第二の脳」のシステム/10_第二の脳セットアップ_Obsidian構築/01_商品設計/コピー素材_unfair_advantage_フレーム.md`（販売文章執筆時はまずここを開く）
