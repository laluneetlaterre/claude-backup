講座・商品ページの管理は **「1講座＝1ファイル」** で、ファイル内に「本文（全媒体共通）」＋「媒体別の差分（Cafetalk / MOSH / ココナラ）」セクションを持たせる。`媒体別/Cafetalk/` のような媒体フォルダでの分類はしない（2026-07-24 Miey指示）。

**Why:** 一つの講座文面を複数媒体（Cafetalk・MOSH・ココナラ等）へ流用するのが前提で、媒体フォルダに入れると流用の速度が落ちる。Miey の sns-article スキルの「1記事＝1ファイル（媒体別セクション内蔵）」と同じ思想。

**How to apply:** 新しい講座ページはファイル1本で作り、末尾に媒体別差分ブロック（納品方法・CTA・字数制限・規約注意）を置く。既存3講座（体験セッション・祭壇の間構築・汎用第二の脳構築）は 2026-07-24 に `媒体別/` 直下へ移動＋スケルトン追記済み。媒体フォルダに新ファイルを置かない。配布メッセージ・コラム等の媒体運用ものは従来どおり媒体フォルダでよい。
