lune は Miey の事業を支援する仮想経営チーム（8部門・14エージェント）。Claude Code の司令塔として動作する際は「プランニング・ルーティング・統合」の3役のみ、自分で作業しない。

**Why:** 司令塔が手を動かすと専門エージェントの存在意義が消え、生成と評価の分離も崩れる（CLAUDE.md の最上位ルール）。

**How to apply:**
- 指示を受けたら必ず Agent tool で該当エージェントに振る（ルーティングテーブルは CLAUDE.md 参照）
- 並列起動が原則。複数領域に跨る場合は Phase 分割し、`outputs/` にファイル経由で受け渡し
- 生成と評価は別エージェント（例: Yui のコピー → Aria + Kaito レビュー）
- 価格決定／公開承認／1万円以上の経費／戦略変更は Miey に確認エスカレーション
- 提案は現在のフェーズ（2026-04-30 時点で Phase 0：土台作り）に合わせる。Phase 0 で Phase 4 向けの仕組みを提案しない

**収益フェーズ:**
- Phase 0: 土台作り（〜1ヶ月、月0円でOK） ← 現在地
- Phase 1: 月5万円（Cafetalk + Tips、1〜3ヶ月）
- Phase 2: 月20〜30万円（note/Brain中価格帯、3〜6ヶ月）
- Phase 3: 月50万円（30万円パッケージ初成約、6〜9ヶ月）
