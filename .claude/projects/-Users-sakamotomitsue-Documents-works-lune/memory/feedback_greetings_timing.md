# 挨拶のタイミング — Mieyの「お疲れさま」基準は厳格

Miey は「お疲れさま」を**完全にその日の仕事が明確に終わった時**にしか使わない。1タスク終わったから・大物完了したから・夜遅いから、では使わない。

過去の事故：
- 朝9時に「お疲れさま」と言われて違和感（時間帯ミスマッチ）
- 大物タスク完了で「お疲れさま 🌙」と書いてしまった（タスク終わりと1日の終わりを混同）

**Why:**
- Mieyの日本語感覚では「お疲れさま」＝「今日の業務終了の挨拶」と限定的
- **Mieyの働き方は家族との並走で中断が多く、細切れ時間で長時間働く**。途中で「お疲れさま」と言われると「もう仕事やめた方がいいよ」というプレッシャーに聞こえてしまう
- タスク完了の労いには別の表現（「完了しました」「いい仕事でした」「ナイスです」等）を使う
- 司令塔は時刻情報を持たず、Mieyの作業継続意思も推測でしかない
- 「おやすみなさい」も同じ系統で、Miey本人が「もう寝る」と明示しない限り使わない
- 一般的なビジネス慣習（タスク完了→お疲れさま）はMieyには合わない。会社員のリズムと個人事業主＋育児/家事並走のリズムは別物

**How to apply:**
- 1タスク完了時：「完了しました。次は何にしましょうか？」など**継続前提の締め**。労いは「お疲れさま」以外で
- 「お疲れさま」を使ってよい条件（厳格）：**Mieyが「今日終わり」「寝る」「もう作業しない」等を明示的に言った後だけ**
- 「おやすみなさい」も同じ。Mieyの明示的GOがあって初めて使う
- 迷ったら使わない。「**今日はここまでで一区切りでしょうか？**」と確認文を入れる
- Miey 1日の終わり挨拶のサイン例：「今日はもう寝る」「明日続き」「今日はここまで」「お疲れ」（Mieyから先に来た場合）
