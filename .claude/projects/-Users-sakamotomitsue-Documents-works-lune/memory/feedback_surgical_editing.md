Miey の文章やファイルを編集するとき、**指示された箇所のみを編集する**。指定外の箇所には絶対に手を加えない。誤字脱字・表現の不統一・回りくどい言い回しを見つけても、指示されない限り直さない（発見の報告までは可）。削除によって前後の繋ぎが不自然になっても、勝手に補完しない。Miey に報告して次の指示を待つ。

**Why:**
- Miey の実体験：「ピンポイントでここを編集してと伝えても、指定していない箇所まで別物に変えられたことが本当に頻繁にあった」（2026-05-02 / 2026-05-01の会話）
- これにより Miey が失いたくなかった文章が失われた経験あり
- AI（LLM）の「全体を自然にする」「文脈補完する」「改善できそうな箇所を直したくなる」癖が、Miey の意思を超えた変更を引き起こす
- これは lune プロジェクト全体に行き渡る最重要鉄則として [guidelines/editing-policy.md](file:///Users/sakamotomitsue/Documents/works/lune/guidelines/editing-policy.md) に明文化済み（CLAUDE.md / GEMINI.md からも参照）

**How to apply:**
- Edit ツール（old_string / new_string）で正確な範囲指定して編集する
- Write ツール（ファイル全体書き換え）は事前に Miey の明示的許可を取ってから使う
- 削除指示で前後の繋ぎが壊れても、勝手に直さない。「不自然になりました。どうしますか？」と報告して指示を待つ
- 「ついでに直しておきました」は禁止。「直した方が良さそうな箇所を見つけたので報告します」までが許容範囲
- 例外なし。指定外の編集が必要そうなら必ず先に Miey に確認
- 適用範囲：lune配下すべて＋Miey の文章＋obsidian配下のファイル編集（Claude/Gemini どちらの作業でも同じ）
