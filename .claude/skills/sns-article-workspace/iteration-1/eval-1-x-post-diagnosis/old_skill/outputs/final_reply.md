【診断】
① フック：✕ 「AIツールってたくさんあるけど」は誰でも書ける導入。1行目で手が止まらない
② 具体性：✕ 「本当に便利」「楽になった」が抽象。数字・場面・固有の体験がない
③ 読みやすさ：△ 短いが改行なしの1ブロック。余白がない
④ 構造：✕ 主張→感想→お願い、で型がない。対比もリストもなし
⑤ ターゲット：✕ 「みんな」宛＝誰にも刺さらない
⑥ 感情トリガー：△ 「結局大事なのは置き場所」という発見の種はある。ここが原石
⑦ CTA・読後行動：✕ 「ぜひ使ってみて」は保存もリポストも生まない締め

核はすでにあります。「ツールより、情報をためる場所」——これは Miey の構造論（蓄積した知性・unfair advantage）そのもの。磨くのは見せ方だけです。

【改善案A：発見型】
AIツール選びで消耗してる人へ。

実は、差がつくのはツールじゃない。
「自分の情報をためておく場所」があるかどうか。

ツールは半年で入れ替わる。蓄積は残る。

私は Obsidian×Claude Code でその置き場を作ってから、毎日の作業が変わった。

→ 効く理由：1行目でターゲット名指し＋「実は」の逆張りで手を止める。「ツールは入れ替わる／蓄積は残る」の対比が引用リポストを誘う言い切り。

【改善案B：原則リスト型】
AIを毎日使って気づいた本質はひとつ。

「どのAIを使うか」より「AIに読ませる自分の情報がどこにあるか」。

①会話は流れる、ファイルは残る
②残った情報は次のAIも読める
③ツールを替えても資産は消えない

だから私は Obsidian×Claude Code に全部ためている。

→ 効く理由：番号リストで読了・保存欲求を刺激。「会話は流れる、ファイルは残る」が持ち帰りたくなる1行＝ブクマシグナルを取りにいく。

【改善案C：短文×構造ビジュアル型】
AI時代の作業環境は、3層で考えるとスッキリする。

②AIが読み書きする知識
