# diary スキル

## 何をするか

今日の diary ファイルの `🤖 AIがやったこと` ブロックに、今日 Claude / Codex / Gemini で完了した主要タスクを書き込む（全AI・全セッション横断。今の会話タブだけに限らない）。AIブロックは**チェックボックスなしの普通の箇条書き**（`- [x]` は取り消し線になって読みにくいため）。チェックボックスは下の `✍️ 自分の作業`（Miey 専用）でのみ使う。

CLAUDE.md Rule 1.3 により、当日分 diary のチェック欄への追記は Miey の明示指示なしに許可されている。

---

## トリガー

以下のいずれかで発動：

- `diary` / `/diary`
- `今日のdiaryに書いて` / `diaryに記録して` / `diaryに書いて`
- `日記に書いて` / `diaryつけて`

## 手順

### 1. 今日の diary ファイルを読む

パス：`/Users/sakamotomitsue/Documents/works/obsidian/03_stock/05_思考_自己分析/diary/YYYY-MM-DD.md`（今日の日付）

※ diary は 2026-07 に vault 直下 `diary/` から `03_stock/05_思考_自己分析/diary/` へ移動済み。過去分は同フォルダの `diary_archive/` にある。

ファイルが存在しない場合は、**本物のテンプレートをそのままコピーして新規作成する**（テンプレの真実の源は1つ。スキル内に直書きしない＝ドリフト防止）：

```bash
cp "/Users/sakamotomitsue/Documents/works/obsidian/00_obsidian_system_files/templates/dairy_template.md" \
   "/Users/sakamotomitsue/Documents/works/obsidian/03_stock/05_思考_自己分析/diary/YYYY-MM-DD.md"
```

このテンプレ構成：「タスク管理」セクションは **`🤖 AIがやったこと`（AIブロック・上）** と **`✍️ 自分の作業`（本人ブロック・下）** の2ブロックに分かれている。さらに「振り返り（本人ゾーン）／ハブ機能（関連ノートへの `[[リンク]]`）」が続く。中身は読まずそのまま複製し、以降の手順で **🤖ブロックにだけ** 書き込む。

※ ただし Miey は通常 Obsidian 側でテンプレをタップして当日 diary を先に作る運用。その場合このコピーは不要で、既存ファイルのチェック欄を埋めるだけでよい。

### 1.5 今日の全AIセッションを集約取得（ゼロLLM・課金なし）

次を実行し、今日（JST 0:00〜24:00）に発生した Claude Code / Codex / Gemini CLI の **全セッション**を取得する（Claude は全タブ・全セッション、さらに Codex・Gemini も横断。セッションは開始時刻の日付で振り分け）：

```bash
python3 /Users/sakamotomitsue/Documents/works/obsidian/00_obsidian_system_files/scripts/ai_session_log.py
```

この出力を「今日 3AI が何をしたか」の主たる情報源とする（今の会話タブだけに頼らない）。スクリプトはログフォルダを読むだけで LLM を呼ばない。引数に `YYYY-MM-DD` を渡せば過去日も取得できる。

### 2. 完了タスクを抽出する

手順 1.5 のスクリプト出力（今日の全AIセッション）＋ 現在の会話コンテキストを合わせて、主要な完了タスクを抽出する。

- **【重複ガード】まず手順1で読んだ diary の `🤖 AIがやったこと` ブロックの既存 `- 【AI名】…` 行を確認し、そこに既にある仕事は抽出対象から外す**。スクリプトは毎回その日まるごと（0:00〜現在）を返すので、これをやらないと再実行時に午前の項目が二重に並ぶ。**前回以降に新しく完了した分だけ**を抽出する（＝日に何度打ってもダブらず、増えた分だけ追記される）。
- **スクリプト出力を主たる情報源にする**（今の会話だけに頼らない＝他タブ・Codex・Gemini の仕事も拾う）
- **同じ仕事を複数AIがやっていたら1行に統合**（例：商品戦略を Claude/Codex/Gemini で検討 → 「商品戦略を3AIで検討」1件）
- **翻訳・使い捨ての質問・生活雑（買い物・家事メモ等）はスキップ**（本人が後で消す手間を増やさない）
- AI の解釈を本人の言葉として書かない（判断主権を奪わない）。振り返り欄（本人ゾーン）には一切触れない
- 対象：ファイルの作成・編集・整理／スキル・ツール・設定／コンテンツ生成（X・記事・資料）／重要な決定・設計

**粒度**：細かい操作単位ではなく「〇〇スキル作成」「△△設定」などのまとまりで書く。1 件あたり 15〜30 文字程度。件数は実作業に応じる（目安 3〜7 件、上限は設けない）。

### 3. 🤖ブロックに書き込む

**AI 名の対応：**
- Claude Code（司令塔）→ `【司令塔】`
- Codex → `【Codex】`
- Gemini CLI / Gemini Code Assist → `【Gemini】`

**書き込みルール：**
- 書き込み先は **`🤖 AIがやったこと` 見出しの直下だけ**。既存の AI `- 【AI名】…` 行があればその下に `- 【AI名】タスク内容` を1行ずつ追記する（**チェックボックス `[x]` は付けない**＝取り消し線で読みにくくなるのを防ぐ。普通の箇条書き `- ` で書く）
- **`✍️ 自分の作業` 見出し以降（自分の欄・振り返り・ハブ機能・その他本文）には絶対に触れない**（本人ゾーン。Miey が自分で書く `- [ ] `／`- [x] ` のチェックボックス行はここに入る）
- 既存の `- 【AI名】…` 行は書き換えない
- **既に🤖ブロックにある仕事は再度書かない（重複ガード／手順2参照）。新規完了分だけを追記する。1日に複数回 `/diary` を打っても安全**
- 新規完了分が無ければ何も書かず「新しく書く項目はなかった」と報告する

**例（書き込み前）：**
```
**🤖 AIがやったこと**（/diary が自動記入・本人は触らなくてOK）

**✍️ 自分の作業**（自分のTODO・やったこと・気づきを自由に書く）
- [ ] 銀行で振込（←Mieyが自分で書いたチェックボックス行。AIは触らない）
- [ ] 
```

**例（書き込み後）：**
```
**🤖 AIがやったこと**（/diary が自動記入・本人は触らなくてOK）
- 【司令塔】diaryスキル作成
- 【司令塔】スキル保存場所の構造確認

**✍️ 自分の作業**（自分のTODO・やったこと・気づきを自由に書く）
- [ ] 銀行で振込（←Mieyが自分で書いたチェックボックス行。AIは触らない）
- [ ] 
```

### 4. 報告する

1 行で報告：`diary に X 件書いた：〇〇、△△、□□`
