# diary スキル

## 何をするか

今日の diary ファイルのチェックリスト欄に、このセッションで完了した主要タスクを書き込む。

CLAUDE.md Rule 1.3 により、当日分 diary のチェック欄への追記は Miey の明示指示なしに許可されている。

---

## トリガー

以下のいずれかで発動：

- `diary` / `/diary`
- `今日のdiaryに書いて` / `diaryに記録して` / `diaryに書いて`
- `日記に書いて` / `diaryつけて`

---

## 手順

### 1. 今日の diary ファイルを読む

パス：`/Users/sakamotomitsue/Documents/works/obsidian/diary/YYYY-MM-DD.md`（今日の日付）

ファイルが存在しない場合は、以下のテンプレートで新規作成する：

```markdown
単なる日記帳というよりはその日に起きたことや考えたことをすべて書き留める情報の入り口のような役割を果たします

- タスク管理 今日やるべきこと今日終わらせたことをメモする

- [ ] 
- [ ] 
- [ ] 
- [ ] 
- [ ] 
- [ ] 



- 振り返り 感情の動きや明日への申し送り

```

### 2. 完了タスクを抽出する

現在の会話コンテキストを見て、主要な完了タスクを 3〜5 件抽出する。

- ファイルの作成・編集・整理
- スキル・ツール・設定のセットアップ
- コンテンツの生成（X 投稿・記事・資料など）
- 重要な決定や設計

**粒度**：細かい操作単位ではなく「〇〇スキル作成」「△△設定」などのまとまりで書く。1 件あたり 15〜30 文字程度。

### 3. チェックリスト欄に書き込む

**AI 名の対応：**
- Claude Code（司令塔）→ `【司令塔】`
- Codex → `【Codex】`
- Gemini CLI / Gemini Code Assist → `【Gemini】`

**書き込みルール：**
- `- [ ] `（末尾スペース含む）を `- [x] 【AI名】タスク内容` に置換する
- スロットが足りなければ、最後の `- [ ]` 行の直後に `- [x]` 行を追加する
- チェック欄以外（振り返り・Phase・優先順位マップ・その他本文）には一切触れない
- 既存の `- [x]` 行は書き換えない

**例（書き込み前）：**
```
- [ ] 
- [ ] 
- [ ] 
- [ ] 
- [ ] 
- [ ] 
```

**例（書き込み後）：**
```
- [x] 【司令塔】diaryスキル作成
- [x] 【司令塔】スキル保存場所の構造確認
- [ ] 
- [ ] 
- [ ] 
- [ ] 
```

### 4. 報告する

1 行で報告：`diary に X 件書いた：〇〇、△△、□□`
