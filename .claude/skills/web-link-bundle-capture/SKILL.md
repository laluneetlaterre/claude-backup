# web-link-bundle-capture スキル（/web-link-bundle-capture）

## 何をするか

1個の `.md`（特典リンクまとめ・リソース集など）の中に並んだ複数のWebリンクを、**1本ずつ手で取り込む手間ゼロ**で、クリーンな Markdown ファイル群に一括変換するスキル。

司令塔（Claude）が：

1. 対象 `.md` 内の通常Webリンクを抽出
2. 画像URL・重複・取り込み不要なものを除外し、**取り込み対象URL一覧を提示**
3. Miey が `ok` / `これは除いて` 等で確認
4. 同名フォルダを作成し、各URLを `defuddle parse` で Markdown 取り込み
5. 元ファイルをそのフォルダへ移動
6. 取り込み件数・失敗URL・保存先を1〜2行で報告

> 単一URLの取り込みだけなら既存の `obsidian:defuddle` で足りる。このスキルは **「1ファイル内の複数リンクを一括で」** という上位ワークフロー。内部で defuddle を回す。

---

## トリガー

以下のいずれかを Miey が、対象 `.md` を指定して入力したら発動：

- `/web-link-bundle-capture`
- `このファイルのリンク全部取り込んで` / `リンクまとめて取り込んで`
- `リンク先を別ファイルにして` / `特典リンク全部Markdownにして`

対象ファイルが明示されていなければ、推測せず Miey に「どのファイルですか？」と確認する。

## 実行フロー

### ステップ 1: リンク抽出（沈黙）

対象 `.md` を読み、本文中の Markdown リンク `[text](url)` と裸URL `https://...` を抽出する。

除外するもの：
- 画像URL（`![](...)`、拡張子 `.png/.jpg/.jpeg/.gif/.webp/.svg`）
- 重複URL（同一URLは1本に）
- 明らかに取り込み不要なもの（`mailto:`、アンカー `#...`、ファイル内部リンク `[[...]]`）

### ステップ 2: 取り込み対象を提示

```
> 対象：clippings/【The Launch Code 5Days】….md
> 取り込むリンク（重複・画像除外後）：7本
>   1. https://example.com/a
>   2. https://example.com/b
>   …
> 保存先フォルダ（新規作成）：<対象と同じ場所>/【The Launch Code 5Days】…/

OK なら取り込みます。除外したいURLがあれば番号で指示してください。
```

### ステップ 3: 確認待ち

`ok` `go` → 実行 ／ `Nを除いて` → 反映して実行 ／ `やめる` → 中止

### ステップ 4: 取り込み実行

1. 対象 `.md` と同じ階層に、**ファイル名（拡張子除く）と同名のフォルダ**を作成。
2. 各URLについて：
   ```
   defuddle parse "<url>" --md -o "<同名フォルダ>/<連番>_<スラッグ>.md"
   ```
   - ファイル名は `01_<タイトルslug>.md` のように連番＋短いスラッグ。タイトルが取れなければURLのドメイン＋パス末尾から生成。
   - 失敗（タイムアウト・403・本文抽出不可）は中断せず、失敗URLとして記録して次へ進む。
3. 全URL処理後、**元の `.md` を同名フォルダへ移動**（中身は触らない）。

### ステップ 5: 完了報告（1〜2行）

```
取り込み完了：7本中 6本成功・1本失敗（403）。保存先 [フォルダ名](相対パス)。失敗URL：https://…
```

## ガードレール（master Rule 1 / 1.1・Rule 2・Rule 3 準拠）

- **clippings/ は保護領域**。このスキルでの処理は ingest 管理（master Rule 1.1）に該当するため、**Miey が明示した対象ファイルのときのみ**実行する。未指定ファイルを推測して処理しない。
- **原文は一切編集しない**。元 `.md` の本文・frontmatter を書き換えない（移動のみ）。整文・要約・誤字修正もしない。
- **フォルダ作成・元ファイル移動は、指定された1ファイルの範囲に限定**。他ファイルを巻き込まない。
- 取り込み結果は**新規フォルダ内の新規ファイル**のみ。既存ファイルを上書きしない（同名があれば連番をずらす）。
- 対象が clippings/ 外でも、編集権限の階層（master Rule 1）を確認してから動く。`diary/` は対象外。
- 取り込み対象が大量（目安：1ファイルで概ね20本超）になる場合は、実行前に Miey に件数を伝えて GO を取る（Rule 3 の主旨）。
- 判定後にスキルが沈黙で実行を始めない。**必ず対象一覧を提示 → 確認待ち**。
- 完了報告は1〜2行。process narration はしない（master §4.2 過剰を出さない原則）。
