# training-log スキル

## 何をするか

Miey の一行報告を、ダッシュボード [トレーニング記録.base](../../../Documents/works/obsidian/03_stock/11_training/dashboards/トレーニング記録.base) が拾える形の **frontmatter だけのログファイル** に変換して保存する。**本文は書かない。**

ベースパス：`/Users/sakamotomitsue/Documents/works/obsidian/03_stock/11_training/`

| 使うもの | パス |
|---|---|
| 保存先 | `logs/YYYY-MM-DD_道場_クラス名.md` |
| 時間割（クラス名・講師の引き元） | `reference/時間割_YYYY-MM.md`（当月ファイル） |
| 書式の正 | `logs/_テンプレート.md` |
| 入口 | `README.md` |

`03_stock/` は共同編集エリア（CLAUDE.md Rule 1.2）なので、新規ファイル作成に Miey の追加許可は要らない。**削除だけは要 GO。**

---

## 手順

### 1. 一行報告から拾えるものを拾う

最低限これだけあれば書ける：**日付・道場・クラス**。

| 項目 | 拾い方 |
|---|---|
| `trained_on` | 言われなければ**今日**。「昨日」「一昨日」も解釈する |
| `dojo` | `下北沢` / `東中野` の2択。打撃系（ボクシング・キック・フィジカル）＝下北沢、寝技系（柔術・レスリング）＝東中野 |
| `start_time` | 「16時」→ `"16:00"`。**必ず引用符で囲む** |
| `participants` | **自分とコーチを除いた**人数。「約9人ぐらい」なら `9` ＋ note に「人数は概算（約9人）」 |
| `weight` / `body_fat` / `condition` | 言われたときだけ。言われなければ**空欄のまま**（推測で埋めない） |
| `note` | 一言だけ（「代講だった」「久しぶりで死んだ」等）。無ければ空欄 |

### 2. 時間割からクラス名・講師を補完する

`reference/時間割_YYYY-MM.md` を読み、**`trained_on` の曜日 × `start_time`** の行を引く。

- `class_name` … 時間割の表記をそのまま使う（例：`総合格闘技（初心者）`）
- `instructor` … 同じ行の講師名。空欄なら空のまま

**日付から曜日を出すときは必ずコマンドで確認する**（暗算しない）：

```bash
date -j -f "%Y-%m-%d" "2026-08-08" "+%A"
```

**引けないときは推測で書かず Miey に一問だけ聞く：**
- その時刻に枠が無い／`フリートレーニング` になっている → 「時間割だと16時はフリートレーニングですが、クラス名は？」
- 当月の時間割ファイルが無い → 「`時間割_YYYY-MM.md` がまだ無いので、クラス名と講師を教えてください」（時間割の新規取得はこのスキルの仕事ではない）
- Miey がクラス名を明示していて時間割と食い違う → **Miey の言葉を優先**し、食い違いを1行報告する

### 3. `category` を11語に寄せる

表記が揺れると「種目別」の集計がバラける。必ずこの中から選ぶ：

`ボクシング` / `キックボクシング` / `柔術` / `ノーギ柔術` / `総合格闘技` / `レスリング` / `フィジカル` / `有酸素` / `コンディショニング` / `ストレッチ` / `フリートレーニング`

例：`総合格闘技（初心者）` → `総合格闘技` ／ `ダイエットフィジカル` → `フィジカル` ／ `有酸素ボクシング` → `有酸素` ／ `キックボクシング（ダイエット）` → `キックボクシング`

### 4. 書き込む

ファイル名：`logs/YYYY-MM-DD_道場_クラス名.md`（例：`2026-08-08_下北沢_総合格闘技（初心者）.md`）

中身は frontmatter だけ。**本文・見出し・振り返り欄は作らない**（開くことがないので埋まらない）：

```
---
type: training-log
trained_on: 2026-08-08
dojo: 下北沢
category: 総合格闘技
class_name: 総合格闘技（初心者）
instructor: 高崎
start_time: "16:00"
weight:
body_fat:
condition:
participants: 9
note:
tags: [training]
---
```

**同じ日・同じ道場・同じクラスのファイルが既にある場合**は、上書きせず既存ファイルを読んで**空欄だけ埋める**（後から体重を言われるケース）。埋める箇所が競合するなら Miey に確認。

**1日に2本出た場合**はファイルが別になるので、そのまま2ファイル作る（ファイル名のクラス名が違うので衝突しない）。同じクラスに2回出た場合だけ末尾に `_2` を付ける。

### 5. 報告する

1行だけ。判断が要らないことは書かない：

```
記録しました → [2026-08-08_下北沢_総合格闘技（初心者）.md](03_stock/11_training/logs/2026-08-08_下北沢_総合格闘技（初心者）.md)
時間割から補完：講師 高崎 ／ participants 9（概算）
```

推測で埋めた項目・時間割と食い違った項目があれば、**そこだけ**1行添える。

## やらないこと

- 「連続日数」を数えない・褒めない・煽らない（README の設計思想：切れた瞬間にやめる原因になる）
- 行かなかった日の記録は作らない
- 体重の増減にコメントしない（聞かれたら答える）
- README・時間割・base ファイルの更新（時間割の月次更新は別作業）
